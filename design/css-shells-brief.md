# Traversence page shells: brief for the CSS rework (2026-11-04)

For the designer (Gemini) reworking the site's look and feel. The site is PHP pages with shared parts. Styles today
are the **Tailwind CDN** (`cdn.tailwindcss.com`, loaded in `app/ui/page-shell.php`) plus small `<style>` blocks inside
each shared part, keyed to short class prefixes (below). Markup is generated by PHP, so the rework is **a theme layer,
not new markup**.

## What to deliver

1. **Design tokens** as CSS custom properties on `:root` (colors, type, radii, shadows, spacing), from `brand.md`.
2. **One stylesheet**, `website/css/tv-theme.css`, styling the **existing class names** listed here, loaded after the
   current styles. New classes only where noted, and only additive.
3. **Mockups** of each shell below at **390px** (phone) and **1280px** (desktop).
4. Nothing that renames or removes a class, changes the HTML, or needs JavaScript; a Claude session wires the stylesheet in
   and moves the old `<style>` blocks onto the tokens.

`system-ui`). **Contrast:** at least 4.5:1 on parchment; visible focus rings.

## Rules the look must keep (CLAUDE.md, decisions/0058 §11)

- **Phone (below 768px), edge to edge:** cards and panels 3px from each side and each other, `.5rem` corners; text
  keeps a small margin. Class `tv-bleed` marks these. No sideways scroll at 390px.
- **Card anatomy:** the name is the link, top left, brand brown underlined; Link button top right; actions (Call,
  Directions, See on map, Website, Contact, Peek) as **30px round icon buttons** down the right edge, icons `#B45309`;
  details on the left.
- **Icons** are the brand's flat SVGs, never emoji. Active: sage with a soft glow; rest: cream with a brown ring.
- **No breadcrumbs** on content pages. **Filters** are one dropdown button (icon, current choice, count, ▾), never rows
  of pills.
- **One look for notices:** green ✓ "Success:" and red ! "Error:" beside the button, else a centered pop-up; status
  lines (`[data-tv-status="ok|info|bad"]`); a **busy spinner** on anything that doesn't finish at once. No browser
  dialogs.
- Card pages (cart, checkout, order) run under a strict content policy: styles must come from our own stylesheet.

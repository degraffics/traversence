- `irs_loads` (and `irs_orgs`) are class **follows** in `app/lib/staging-tables.php:65` (copied from live; never
  carried back).

  the night (`StagingSync::followTables()`, `StagingSync.php:620–640`), across all four realms: main, admin, listings
  and users (`StagingSite::liveDbs()`, `StagingSite.php:154–164`). So wherever `irs_loads` lives, staging holds
  last night's copy.
